# Пейвол Magic Tricks — план редизайна

Методика: скилл `app-paywall-pilot` (режим `design`, выходной контракт) и скилл
`frontend-design` (план в два прохода, проверка на шаблонность, самокритика по
скриншотам). `paywall-upgrade-cro` Skill-инструмент вызвать не даёт (в заголовке
скилла `disable-model-invocation: true`), его шаги не применялись.

## Статус intake (по app-paywall-pilot)

- Known: iOS, SwiftUI, свой StoreManager (без RevenueCat/Adapty), один продукт
  `magic_lifetime` (разовая покупка, не подписка, пробного периода нет), цена
  из StoreKit ($9.99 в StoreKit-конфиге), четыре входа (конец онбординга,
  Get Pro, закрытый трюк, бейдж ватермарки), Restore/Terms/Privacy есть.
- Missing: метрик воронки нет (аналитики в приложении нет), для режима `design`
  это не блокирует.
- Risk: победителя по тексту/композиции определить нельзя, только через
  конверсию в App Store Connect после релиза.
- Mode: design.

## Факты для текстов (сверять каждую фразу)

- Покупка одна, разовая, не подписка, без пробного периода, цена из StoreKit.
- Бесплатно 1 трюк (Geo Mentalism). Покупка открывает ещё 5: Color Sense,
  Calculator Prediction, Time Control, Magic Gallery, Phantom Draw.
  Всего 6. Фраза "покупка открывает 6" неверна.
- Ватермарка убирается (не подчёркивать). Никаких отзывов, срочности,
  зачёркнутых цен.

## Recommended model (access, placement, presentation, surface)

- Access: freemium (1 трюк бесплатно) + разовая покупка остальных.
- Placement: четыре входа; из закрытого трюка экран говорит про этот трюк.
- Presentation: один экран, одна цена, одно действие, без выбора плана.
- Surface: кастомный SwiftUI-экран поверх StoreKit.

## Проход 1. План (frontend-design)

Тема продукта: фокусы, где магия в секрете, а сигнал чувствует только фокусник,
через вибрацию телефона. Собственный язык продукта: легенда "0 = длинная
вибрация, 1–9 = столько вибраций" (HapticTraining), сигнал это импульс.

### Три принципиально разные композиции

**A. Постер с ценой и ряд монет** (то, что уже в ветке, чанки 2–3).
Центр, гигантская цена, одна оранжевая монета и пустые пунктирные.
```
        ( X )
  Pay once. Keep it forever.
        $9.99
  ○ ◌ ◌ ◌ ◌ ◌ ◌ ∞
```
Оценка: читается быстро, но это "большое число плюс градиентный акцент", то
самое типовое решение. Лица нет.

**B. Маскировка под калькулятор.** Экран-калькулятор, на дисплее `9.99 × 1`,
большая клавиша "=" вместо кнопки покупки.
```
 ┌───────────────┐
 │       9.99 × 1│
 │      = 9.99   │
 │ [ = Pay once ]│
 └───────────────┘
```
Оценка: связано с идеей маскировки, но путается с трюком Calculator Prediction
(человек решит, что платит за него), копирует вид системного приложения.

**C. Импульс и ровная линия.** Сигнал в языке продукта: один высокий импульс
(платёж сегодня), дальше ровная линия, которая уходит за правый край экрана
(навсегда). Слева выровненный крупный текст, слева же цена.
```
                                 ( X )
  Pay once.
  Keep it forever.

  $9.99
  one payment, no subscription

  ────────╱╲────────────────────────→
  today

  5 more tricks: Color Sense, Calculator
  Prediction, Time Control, Magic Gallery
  and Phantom Draw. Geo Mentalism stays free.

  [        Pay $9.99 once        ]
   Nothing renews. Nothing to cancel.
   Restore purchases · Terms · Privacy
```
Оценка: обещание читается картинкой за секунду (один импульс, потом тишина
навсегда), язык взят из самого продукта, "навсегда" не нужно рисовать знаком
бесконечности, линия просто не кончается. Выбрана композиция C.

### Токены

- Цвет (использовать ассеты, новых не заводить): фон `backgroundScreen`
  (светлая #F6F3F7, тёмная из ассета), текст `textPrimary` (светлая #1C1C1E),
  вторичный `textSecondary`, импульс в градиенте Pro (#FF9414 → #FF476B) на
  общем экране и в цвете трюка на контекстном, кнопка `textPrimary` на
  `backgroundScreen` как сейчас.
- Шрифт: SF Rounded (так задано дизайн-системой приложения). Цена heavy 72pt
  (самый крупный текст, масштабируется), заголовок bold title, остальное
  medium/regular. Выравнивание по левому краю.
- Цвет и тяжесть тратятся в одном месте: импульс. Цена тёмная без градиента.

### Принципы

- Одна запоминающаяся вещь: линия с одним импульсом.
- Никаких карточек, плиток, таблиц, списков с галочками.
- Одна анимация: линия прорисовывается слева направо, на импульсе играет
  один лёгкий хаптик. Reduce Motion: статичная линия, без хаптика.

## Проход 2. Проверка плана на шаблонность

Что изменено после проверки на соответствие брифу и на типовые приёмы:

- Убрана центровка и сеточная симметрия, текст и цена по левому краю
  (типовой центрированный постер отвергнут).
- Убрано свечение и градиент на монете и на цене: градиент остался только на
  импульсе, чтобы не получилась "карточка SaaS с градиентной заливкой".
- Убран знак ∞ и пунктирные кружки: ряд из семи кружков это тот же ряд
  плиток по кругу, линия обходится без повторяющихся элементов.
- Нет капслока, подписей-эйбровов, точек-разделителей в служебных строках.
  Ссылки Restore, Terms, Privacy остаются как навигация.
- Монета с галочкой убрана: галочка это язык списка из забракованного дизайна.

## Copy draft (en / es)

- Заголовок: "Pay once. Keep it forever." / "Paga una vez. Tuyo para siempre."
- Под ценой: "one payment, no subscription" / "un solo pago, sin suscripción".
- Метка под импульсом: "today" / "hoy".
- Что получаю: "5 more tricks: <названия>. Geo Mentalism stays free." Число
  берётся из количества Pro-трюков, склонение через plural variations.
- Контекст: "Unlock <трюк>", строка про то, что трюк делает, затем остальное.
- CTA: "Pay $9.99 once" / "Pagar $9.99 una vez" (действие и цена, 4 слова).
- Строка доверия: "Nothing renews. Nothing to cancel." /
  "Nada se renueva. Nada que cancelar."

## Compliance watchouts

- Apple Guidance (HIG In-app purchase): итоговая цена видна и самая крупная.
- Restore, Terms, Privacy доступны на экране. Зона нажатия не меньше 44pt
  (кнопка Restore сейчас ниже, поправить).
- Цена только из StoreKit, плейсхолдер на загрузке, ошибка с Retry.
- Хаптик декоративный, ничего не обещает и не блокирует интерфейс.
- Field Report (не правило Apple): шрифт цены не меньше 16pt, у нас 72.

## Первый тест

После релиза сравнить конверсию просмотров экрана в покупку (App Store
Connect, аналитики в приложении нет): "Pay once. Keep it forever." против
подачи через результат ("5 more tricks. One payment."). Гипотеза, не вывод.

## Не делаем

Планы, подписку, пробный период, зачёркнутые цены, выдуманный соцпруф,
срочность, изменения в StoreManager и логике покупок.
