# План: третий раунд ревью и замечания к релизу

Источники: 68 новых тредов и сводка в [PR #1](https://github.com/extrafa/Magics/pull/1), 3 старых
нерешённых треда там же, присланные заметки (риски App Store, фокусы со стороны зрителя, процесс
релизов, работа с тредами). Открытых issues нет. Состояние кода: `develop` @ `ffa1f5b` плюс то, что
смержено после.

Строки с `///` это заметки владельца: Claude их не удаляет и не переписывает. Правишь план прямо
здесь, потом "обнови по моим правкам".

## Правила работы с этим планом

- Один пункт R-xx = один PR. Поведение, строки, инструкции и отметка в `docs/achievements.md`
  идут в одном PR (замечание ревью: поменяли поведение, а тексты остались старые).
- Перед каждым пунктом: формулировка и последствия, жду "ок". "ок" на один пункт не переносится.
- Мерж только после зелёного CI. Размер PR до ~400 строк, большое режем.
- Окно оценки (задача 40) и всё с ним связанное это самый последний пункт (R-90), не раньше.
- Не трогаю то, что владелец делает сам: слайды онбординга и мокап (4), живое тестирование (6),
  содержание Help (18), App Store Connect (10, 11, 12, 15), решения 36, 44, 45. Инструкции (2) я правлю
  только там, где мои изменения сделали их ложными (R-01, R-02) и где ты разрешил.
