# Пейвол Magic Tricks — план редизайна (v2, с нуля)

Методика: скилл `app-paywall-pilot` (режим `design`) и скилл `frontend-design`
(план в два прохода, проверка на шаблонность, самокритика по скриншотам).
Предыдущие варианты отвергнуты: ряды и карточки с галочками, веер экранов
телефона, таблица Free vs Pro, постер с огромной ценой и линией-импульсом.

## Статус intake

- Known: iOS 16+, SwiftUI, свой StoreManager, один продукт `magic_lifetime`
  (разовая покупка, не подписка, без пробного периода), цена только из
  StoreKit. Показ: в конце онбординга (первый раз) и по нажатию на закрытый
  трюк (контекстный вариант), плюс Get Pro и бейдж ватермарки.
- Missing: аналитики нет, победителя можно определить только по App Store
  Connect после релиза. Для режима `design` не блокирует.
- Mode: design.

## Факты для текстов (сверять каждую фразу)

- Бесплатно 1 трюк (Geo Mentalism). Покупка открывает ещё 5: Color Sense,
  Calculator Prediction, Time Control, Magic Gallery, Phantom Draw.
  Фраза "покупка открывает 6" неверна. Число берётся из каталога.
- Покупка одна, разовая, без подписки и пробного периода. Ватермарка
  убирается (упоминается мелко, не подчёркивается). Никакого соцпруфа,
  срочности, зачёркнутых цен.

## Recommended model

- Access: freemium + разовая покупка. Placement: конец онбординга и закрытый
  трюк. Presentation: один экран, одна цена, одно действие. Surface: свой
  SwiftUI-экран поверх StoreKit.

## Проход 1. План

Тема: фокусник и колода карт. Пять Pro-трюков это пять карт рубашкой вверх,
покупка переворачивает их лицом.

Цвета (из ассетов приложения, новых не заводим):
- фон `backgroundScreen` (#F6F3F7 / #1B1B1B), текст `textPrimary`;
- рубашка карты: фиолетовый градиент иконки #7B2FE0 → #B030B0 с золотой
  искрой #FFB62E;
- лицо карты: белый #FFFFFF, значок трюка в его цвете (colorSense #AF52DE,
  calculator #FF9500, timeControl #32ADE6, magicGallery #5856D6,
  phantomDraw #FF375F).

Шрифт: SF Rounded (язык приложения). Заголовок heavy ~34pt, остальное
medium/regular. Выравнивание по левому краю.

Раскладка: веер из пяти карт растёт из левого нижнего угла героя и
раскрывается вправо (асимметрия, как карты в руке). Под ним текст слева,
внизу закреплённая панель с кнопкой.
```
                              ( X )
  
          ╱▔▔╲
       ╱▔╲╱▔╲╱▔╲       <- веер, карты рубашкой, потом переворот
      ╱▔╲▕  ▕ ╲▔╲
     ▕   ▏
  Pay once.
  Keep it forever.
  5 more tricks: Color Sense, ... Geo Mentalism stays free.
  ───────────────────────────────
  [        Pay $9.99 once        ]
   Nothing renews. Nothing to cancel.
   Restore purchases   Terms   Privacy
```
Контекстный вариант: нажатая карта лежит сверху веера, приподнята и уже лицом;
заголовок "Unlock <трюк>", строка о том, что трюк делает.

Движение: одно, при открытии. Карты раскладываются веером рубашкой вверх и
по очереди переворачиваются лицом. Reduce Motion: сразу лицом, без движения.

## Проход 2. Проверка на шаблонность

- Центрированный герой плюс заголовок плюс кнопка это шаблон paywall: ушли
  в асимметричный веер с центром вращения слева и левое выравнивание текста.
- Огромная цена и градиентная заливка отвергнуты: цена живёт в кнопке и
  читается как "Pay $9.99 once", отдельного числа-героя нет.
- Нет галочек, списков, таблицы, плиток, подписей капсом, нумерации, замков:
  лишь рубашка и лицо карты.
- Градиент только на рубашке (это цвет иконки приложения), не как декор.

## Copy

- Заголовок: "Pay once. Keep it forever." / "Paga una vez. Tuyo para siempre."
- Строка под ним: "5 more tricks: <названия>. <Free> stays free."
- Контекст: "Unlock <трюк>", эффект трюка, "Plus 4 more tricks: ...".
- Кнопка: "Pay $9.99 once" (цена из StoreKit). Доверие: "Nothing renews.
  Nothing to cancel."

## Compliance

- Цена видна на кнопке, Restore, Terms, Privacy на экране (зона 44pt),
  закрытие видно. Цена только из StoreKit, ошибка с Retry. Анимация
  декоративная и не блокирует кнопку. Apple Guidance (HIG In-app purchase).

## Первый тест

После релиза: "Pay once. Keep it forever." против "Unlock 5 more tricks"
(просмотры в покупки, App Store Connect). Гипотеза, не вывод.

## Чанки (один чанк, один коммит)

1. Модель текстов без таблицы и строк.
2. Веер карт статично и новый экран, удаление старых файлов.
3. Раскладка и переворот карт, Reduce Motion.
4. Контекстный вариант, строки en/es, тесты.
5. Проверка в симуляторе (тема, текст, SE) и полировка.
