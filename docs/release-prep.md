## 1. Чек-лист живого тестирования

Идти на реальном телефоне со сборкой из TestFlight (схема Magics (TestFlight)) и
вторым телефоном для Phantom Draw. Для каждого пункта цель двойная: "работает как
задумано" и "что будет, если сломать".

### Сквозное
- [ ] Чистая установка (удалить приложение): онбординг от приветствия до пейвола,
      кнопка закрытия на пейволе, после неё хаб
- [ ] Покупка в песочнице: Pay → открылись 4 трюка, исчезла ватермарка, пейвол закрылся,
      кнопка "Unlock" на хабе пропала
- [ ] Отмена покупки на системном листе: приложение не зависает, кнопка снова нажимается
- [ ] Restore после переустановки и на втором устройстве
- [ ] Без сети: пейвол показывает ошибку магазина с Retry, после включения сети Retry работает
- [ ] Хаб: Start и Learn на закрытом трюке открывают пейвол с названием этого трюка
- [ ] Настройки: переключатель подсказки выхода, настройки вибраций, тренажёр вибраций, Help,
      Privacy и Terms открываются, письмо в поддержку открывается, Restore
- [ ] Окно оценки после 3 закрытых трюков: "понравилось" открывает системный запрос,
      "не понравилось" открывает письмо
- [ ] Светлая и тёмная тема, английский и испанский, крупный шрифт (Dynamic Type),
      Reduce Motion, экономия энергии
- [ ] Прерывания посреди трюка: блокировка экрана, звонок, уход в фон и возврат,
      беззвучный режим, уведомление сверху

### Geo Mentalism (бесплатный)
- [ ] Первый раз: обучение выходу (удержать в углу 1.5 с, "Got It"), потом подсказка гаснет
- [ ] Список городов, выбор, экран из 10 городов, кнопка Shuffle много раз
- [ ] Сломать: быстрые частые тапы, возврат назад посреди, уход в фон
- [ ] Проверить правило: 9 городов одного типа первой буквы и 1 другого, в нескольких прогонах
- [ ] Ватермарка видна без покупки и пропадает после

### Color Sense
- [ ] Вибрации 1 (красный), 2 (зелёный), 3 (синий), 4 (жёлтый) совпадают с тапами
- [ ] Сломать: два быстрых тапа подряд, тап во время вибрации, фон во время вибрации
- [ ] Настройки вибраций: крайние значения скорости и силы, группировка, тренажёр

### Time Control
- [ ] Старт и стоп секундомера; секунды приходят сразу, сотые через 3 секунды
- [ ] Ноль (длинная вибрация) в секундах и в сотых, время меньше секунды, больше минуты
- [ ] Триггер "Face Down" включён и выключен, сигналы по одному
- [ ] Сломать: двойной тап по старт/стоп, блокировка во время работы, фон, долгий секундомер
      (экран не гаснет)

### Magic Gallery
- [ ] Standard Set включён: 10 стандартных фото в сетке, выступление показывает их
- [ ] Add Photos при включённом Standard Set: он выключается, пикер открывается
- [ ] Добавление: камера и библиотека, кадрирование, "Use Photo", последовательная съёмка,
      все 10 слотов заняты (сообщение), удаление фото (анимация, подтверждение)
- [ ] Права: камера запрещена, доступ к фото ограниченный, добавление в галерею запрещено
- [ ] Выступление: 1-10 тапов, пауза больше 1.2 с сохраняет раньше срока, 11 тапов сбрасывает,
      номер без фото (сообщение с номером), сохранённая фотография появляется в галерее
- [ ] Сломать: фон во время выступления, мало места на телефоне

### Phantom Draw (два телефона в одной сети)
- [ ] Права на локальную сеть: разрешить и запретить (что видит человек)
- [ ] Сопряжение: верный код, неверный код, два отправителя рядом, повторное подключение
- [ ] Рисование на стороне зрителя видно у приёмника в реальном времени, очистка корзиной
- [ ] Выход: 4 быстрых тапа по корзине закрывают трюк, 3 тапа нет, пауза обнуляет счёт
- [ ] Двузначное число (импровизация из инструкции), очень длинные штрихи и много штрихов
- [ ] Сломать: Wi-Fi выкл/вкл, блокировка одного телефона, фон, бейдж "Reconnecting" и
      возврат "Connected", заголовок не прыгает
- [ ] Телефон зрителя (sender): выключить Local Network до подключения, должен быть экран "Local Network
      Is Off" и рабочий Try Again; во время рисования выключить и включить Wi-Fi или вернуться из фона,
      холст остаётся холстом (без "Could Not Connect"), у приёмника "Reconnecting" и снова "Connected"
- [ ] Пропажа телефона зрителя: выключить на нём Wi-Fi (или включить авиарежим), приёмник в течение ~10 с
      должен показать "Reconnecting", а не остаться на зелёном "Connected"; после включения снова "Connected"
- [ ] Переподключение приёмника: выключить и включить Wi-Fi на телефоне фокусника, "Reconnecting" и снова
      "Connected" в пределах нескольких секунд; у зрителя холст на месте, рисунок появился у приёмника.
      Если есть третье устройство: подключиться с неверным кодом во время показа, основное соединение не рвётся
- [ ] Штатное закрытие трюка зрителем: 4 тапа по корзине на телефоне зрителя, у приёмника сразу "Session
      Ended" (без 15 с "Reconnecting" и без "Could Not Connect"), "Close" закрывает экран, "Try Again" ищет
      заново. Отдельно: выключить Wi-Fi на телефоне зрителя, не закрывая трюк, приёмник остаётся на
      "Reconnecting", а не на "Session Ended". Если на реальных телефонах обрыв Wi-Fi тоже показывает
      "Session Ended", записать сюда: тогда нужен явный сигнал выхода (.bye)
- [ ] Выход приёмника (крестик слева) и повторный вход

## 2. Черновик Review Notes для App Review (на английском)

Вставляется в App Store Connect, поле "Notes". Угловые скобки это то, что нужно
заполнить или проверить тебе. Я проверил только то, что видно в коде.

```
Magic Tricks is a toolkit of mentalism tricks that a person performs for friends using
only a phone. There are no accounts, no analytics, no ads and no backend: the app
collects no data. Every trick is explained inside the app (the "Learn" button on each
card), and everything the app does is described there. There are no hidden or
undocumented features.

How the secret works: some tricks pass information to the performer through the phone's
vibrations, which only the person holding the phone can feel. The vibration code and how
to practise it are described in the instructions and in Settings > Practice Signals.

In-app purchase: one non-consumable product, "magic_lifetime" (a one-time payment, no
subscription). One trick (Geo Mentalism) is free; the purchase unlocks the other four
tricks and removes the watermark. Restore Purchases is on the paywall and in Settings.

Phantom Draw needs two devices on the same local network (one device is given to the
spectator, the other stays with the performer; they pair with a two-digit code). The app
asks for the Local Network permission for this, and it is used only to connect these two
devices directly; no data goes through any server. A short demo video of this trick is
here: <link to a demo video>. All other tricks can be tested on a single device.

Magic Gallery uses the camera or the photo picker to get numbered photos (stored only
inside the app) and asks for add-only access to Photos to save one photo when the
performer chooses to.

Contact for review questions: <your email>.
```

## 4. Архив и загрузка в App Store Connect

Схема "Magics (TestFlight)" собирает конфигурацию Beta: в ней есть секция "TestFlight" с
переключателями "Pro Access Override" и скрытием ватермарки. У Beta и Release одинаковые bundle id и
версия, поэтому в App Store Connect такие сборки не отличить по номеру.

- [ ] Убрать `Config/Local.xcconfig` (он подменяет bundle id и команду), только потом архивировать
- [ ] Архивировать только схемой "Magics" (Release), не "Magics (TestFlight)" и не "Magics (StoreKit Test)"
- [ ] Версия и номер сборки не повторяют уже загруженные (выбор версии это пункт 36)
- [ ] Поставить из TestFlight именно загруженную сборку и открыть Настройки: секции "TestFlight"
      с переключателями быть не должно, закрытые трюки должны оставаться закрытыми. Если секция
      есть, это Beta: не отправлять её на ревью
