# 2026-09-14 — сгруппированный тактильный сигнал через CHHapticPattern

## Что решалось

Тред из PR #1 ("First review"): `playGroupedCountSignal` строил
сгруппированный тактильный сигнал через цепочку таймеров
`DispatchQueue.main.asyncAfter`, что на плотном интервале (0.10-0.15 с)
могло смещать импульсы при загрузке главного потока и размывать границу
между группами.

## Что сделано

- Новый `GroupedHapticPatternBuilder` строит единый `CHHapticPattern`
  (по аналогии с уже существующим `TimeHapticPatternBuilder`).
- `playGroupedCountSignal` играет этот паттерн через `HapticEnginePlayer`,
  таймерная логика вынесена в приватный `playGroupedCountFallback` и
  используется только как fallback для устройств без CoreHaptics.
- При первой реализации `completion` был перенесён на `scheduleCompletion`,
  которая добавляет `completionPadding` (0.1 с) — на этапе финальной
  сверки с acceptance criteria это расхождение с исходным поведением
  нашлось и было исправлено отдельным коммитом (completion теперь
  вызывается ровно в момент последнего импульса, без лишней задержки).
- PR #84, смержен squash-мерджем в develop.
