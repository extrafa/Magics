## Грабли
- **Один раз закоммитил прямо в `develop`**, забыв создать fix-ветку перед
  чанком (MagicGalleryViewModel PR). Заметил по ошибке `git push` (ветка не
  существует). Исправил: `git branch <name>` на текущем HEAD, затем
  `git reset --hard origin/develop`, затем `git checkout <name>` — коммит
  сохранён, `develop` не пострадал. Работало только потому, что коммит ещё
  не был запушен в origin/develop.
- **Пользователь один раз запустил спавненный `spawn_task`-чип не глядя**,
  из-за чего задача (фикс сломанных тестов) параллельно стартовала в другой
  сессии — попросил больше не пользоваться `spawn_task` вообще. Сохранено в
  память (`no_spawn_task.md`).
- **Редактирование `Localizable.xcstrings` через Python `json.load`+`json.dump`
  пересобирает весь файл** (другой порядок ключей/отступы) — диф выходит на
  тысячи строк вместо одной. Откатил, вырезал/добавил запись точечным Edit
  по тексту. Существующая память про диф-чек это ловит постфактум; стоило
  бы не пытаться JSON-инструментом вообще.
- **Инструмент скриншота симулятора (`captureFailed`) отвалился посреди
  визуальной проверки** и не восстановился за несколько попыток — визуальную
  проверку одного PR пришлось заменить на юнит-тесты чистой геометрии плюс
  ручной код-ревью, явно предупредив пользователя в PR-описании.
- **Двусмысленная "оптимизируй всё" почти всегда означала**: сверка с планом
  реализации (Этап 6) плюс точечная зачистка в файлах, которые реально
  трогали в этом PR — не карт-бланш на более широкий рефакторинг.
